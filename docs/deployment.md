# 部署與跨團隊使用說明

離職洞察工具是**單一 HTML 檔**，所有計算都在使用者自己的瀏覽器中完成，不連任何網路。
所以它可以放在公司雲端資料夾分享給各團隊。不過開啟方式有一個關鍵限制，以下說明。

## 1. 關鍵限制：要「同步到本機後開啟」，不能在網頁版直接點開

| 放置位置 | 在網頁上點開 | 同步到電腦後雙擊開啟 |
|---|---|---|
| SharePoint／OneDrive 網頁版 | ✗ 不會執行，只會下載或顯示原始碼 | ✓ 用 OneDrive 同步程式 |
| Google Drive 網頁版 | ✗ 只能預覽原始碼 | ✓ 用 Google 雲端硬碟電腦版 |
| NAS／網路磁碟機 | 不適用 | ✓ 從檔案總管直接雙擊 |

雲端硬碟基於安全，不會在網頁上執行 HTML 裡的程式。
做法是讓檔案出現在電腦的檔案總管，再雙擊用 **Edge 或 Chrome** 開啟。

## 2. 建議的資料夾結構與權限

| 資料夾 | 放什麼 | 權限 |
|---|---|---|
| `01_工具正式版` | `離職洞察工具_v1.0.html`、使用手冊 | 所有人唯讀，只有維護者能更新 |
| `02_各團隊設定檔` | `設定檔_團隊名.json`（欄位對應、分類表、門檻） | 各團隊 HR |
| `03_HR限定` | ERP 匯出的原始 Excel、新人關懷名單 | 只開放 HR |
| `04_主管報告` | 主管版報告（只有彙總數字） | 主管可看 |

- 原始 Excel 與關懷名單含個資，**只能放在 `03_HR限定`**。
- 工具本身不保存任何資料，關閉瀏覽器就清空。
- 這個雲端資料夾不要放進開發用的專案資料夾（Git repo）裡。

## 3. 可能遇到的障礙與對策

| 障礙 | 對策 |
|---|---|
| 公司信箱或資料外洩防護（DLP）封鎖 `.html` 附件 | 改用共用資料夾分享，不用寄信 |
| 瀏覽器對「從網路下載的檔案」跳出安全警告 | 請資訊部門把共用資料夾路徑列為信任位置 |
| 多人同時存檔造成同步衝突 | 輸出檔依「日期_團隊」命名，例如 `2026-10_北區_主管報告.html`，不同人不覆蓋同一個檔案 |
| 各人手上的版本不一致 | 只從 `01_工具正式版` 發布；工具畫面顯示版本號；舊版移到「封存」子資料夾 |
| 資安審查 | 提供兩項證明：(1) 工具內建安全政策（CSP）禁止任何連線；(2) 拔掉網路線實測，工具照樣正常運作 |
| 雲端硬碟「僅線上」檔案開不起來 | 在檔案上按右鍵，選「一律保留在此裝置上」 |

## 4. 跨團隊與日後擴充路線

1. **共用資料夾發布**（立即可行）：依上述結構，各團隊自行用自己的設定檔操作。
2. **集團彙總**：各團隊只交出「彙總包」（無個資、人數少於 5 人已遮蔽），由工具合併成跨團隊總覽。
3. **內網網站**：請資訊部門把工具放到公司內網的靜態網站（例如 IIS）。
   - 大家用同一個網址，版本集中更新
   - 計算仍在各人瀏覽器內完成，資料不經過伺服器，個資原則不變

## 5. 開發者注意

- 開發時的資料防護規則見專案根目錄的 `CLAUDE.md`。
- 發布到 `01_工具正式版` 前，確認：測試全數通過、檔名與工具畫面都有版本號、用假資料走過一次完整流程。
